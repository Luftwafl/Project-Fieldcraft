KNOWN LIMITS (also in the in-game changelog)
- Only one active login per account: logging in elsewhere signs out the other browser.
- Only the wallet (cash, scopes, stats) is saved to the account; settings stay per browser.
- Multiplayer is human-only (no NPC sync) and trust-based: the server relays client-reported shots, hits and deaths without checking them.
- Admins are account names in config.json. Register those names yourself before others can; a name can be taken by whoever registers it first.
- Passwords are hashed, but logins run over plain HTTP unless the server sits behind HTTPS.
- Accounts are stored in accounts.json next to server.js; back it up to keep them.
